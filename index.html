QUESTIONS BEFORE YOU DOWNLOAD?

Frequently asked questions.

What is the difference between Community and Pro?

Community provides the core command-library experience. Pro adds premium productivity, protection, and update-related features such as automatic backup capabilities, advanced backup retention, and Command Pack updates.

Do I need to purchase Pro before downloading Command Vault?

No. Download Command Vault and start with Community. You can upgrade to Pro later without rebuilding your command library.

Where is my command library stored?

Command Vault stores your library locally on your Windows computer using SQLite. Your normal command-library workflow does not require a cloud-hosted command database.

Does Command Vault require an internet connection?

The desktop command library is local-first. Internet access is needed for activities such as downloading releases, purchasing a license, receiving license email, and accessing online support or updates.

How do I activate Pro?

After purchasing Pro, you receive a signed .cvlicense file by email. In Command Vault, open Settings → License → Activate License and select that file.

What is the difference between Annual and Lifetime Pro?

Pro Annual is $39 per year. Pro Lifetime is a $79 one-time purchase for the licensed Command Vault product and does not require a recurring subscription.

Are Command Packs included with Pro?

Command Packs are separate products. Pro enables Pack Updates and other Pro capabilities, but individually priced packs are purchased separately unless a specific offer says otherwise.

What Windows version does Command Vault support?

The current release is distributed for Windows x64 and is published as a self-contained application, so a separate .NET installation is not required.

Can I verify the download?

Yes. Each public release includes a SHA-256 checksum so you can verify the downloaded ZIP against the published release file.

Where do I get support?

Email support@commandvaultapp.com or visit the Support page.
