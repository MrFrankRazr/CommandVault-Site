# CommandVault-Site

Public marketing site for **Command Vault — The IT Professional's Command Library**.

This repository is intentionally separate from the private Command Vault application source repository. It should contain only public-facing static website assets.

## GitHub Pages

1. Open **Settings** in this repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

The site should become available at:

`https://mrfrankrazr.github.io/CommandVault-Site/`

## Security rule

Never add private signing keys, API keys, `.env` files, private release packages, or files from `C:\CommandVault-Secrets` to this repository.
