Command Vault Support

For product, licensing, download, billing, or technical assistance, contact:

Email: support@commandvaultapp.com

What to Include

Providing the following information helps us investigate efficiently:

  • Your Command Vault version, such as 1.1.0.
  • Your Windows version and whether you are using Windows x64.
  • A clear description of what you expected and what happened instead.
  • The exact error message, if one appears.
  • Relevant screenshots, provided they do not expose passwords, API keys, private keys, access tokens, confidential commands, or other sensitive information.
  • For licensing or purchase issues, the email address used for the purchase and, if available, a transaction or receipt identifier.

License Activation

Paid Command Vault licenses are delivered as signed .cvlicense files. To activate a license in Command Vault, open Settings → License → Activate License and select the license file you received.

Missing License Email

If you completed a purchase but did not receive your license email, check your spam or junk folder first. If the license is still missing, contact support using the purchase email address so we can locate the fulfillment record.

Downloads and Release Verification

The current Windows x64 release is available from the official Command Vault GitHub Releases page. A SHA-256 checksum is published alongside the release so you can verify the downloaded ZIP.

View official Command Vault releases

Before Running Technical Commands

Commands stored in or supplied with Command Vault can make significant changes to systems and data. Review and understand a command before executing it, test where appropriate, use least-privilege access, and maintain suitable backups.

Security and Sensitive Information

Do not send passwords, payment-card numbers, private cryptographic keys, authentication tokens, API secrets, or other credentials in a support request. If diagnostic material contains sensitive information, redact it before sending.
